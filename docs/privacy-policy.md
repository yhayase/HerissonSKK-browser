# HerissonSKK プライバシーポリシー

更新日: 2026-09-23

このポリシーは HerissonSKK for Firefox と HerissonSKK for Chrome に適用します。

## 入力と保存

日本語入力のため、対象の入力欄でのキー操作とテキストを扱います。かな漢字変換はブラウザー内で処理します。拡張機能が入力内容や登録語を変換サーバーへ送信することはありません。個人辞書、学習した候補順、システム辞書の設定と取得済み辞書は、利用中のブラウザープロファイル内に保存します。拡張機能によるブラウザー間・端末間の同期はありません。

Web ページに入力・確定した文字は、そのページから利用できます。入力先サイトによる情報の取り扱いは、そのサイトのポリシーに従います。

## 外部との通信

初回起動時に、基本辞書 S を GitHub の raw.githubusercontent.com から自動取得します。初回取得にはインターネット接続が必要です。取得後はブラウザー内に保存し、通常の起動時に再取得しません。追加辞書の取得・更新を行う場合は、選択した辞書の配信先へ通信します。標準の外部辞書は GitHub の raw.githubusercontent.com から取得します。独自の URL を指定した場合は、その配信先へ通信します。

辞書の取得要求に、変換中の読み、登録語、ページの入力内容を含めません。配信先には IP アドレスなど通信に必要な情報が伝わります。辞書取得では Cookie 等の認証情報を送らない設定を使用します。URL に機密情報を含めないでください。

ローカルファイルから読み込んだ辞書は外部へアップロードしません。アクセス解析や広告配信のための通信は実装していません。

## 権限

入力支援のため、対象の Web ページの入力欄にアクセスします。辞書と設定を端末内に保存する機能、標準の外部辞書を取得する権限を使用します。独自の配信先から辞書を取得する場合は、その配信先へのアクセス許可を要求します。

## 削除と診断

辞書を無効にしても取得済みデータは残ります。拡張機能を削除するか、ブラウザーの機能で拡張機能の保存データを削除すると、そのプロファイルの保存データが失われます。現時点では個人辞書のインポート・エクスポート用画面はありません。

エラー時にはブラウザーの開発者向けコンソールに読みなどが記録される場合があります。ログや画面を他者へ共有する際は、公開したくない情報を除いてください。

## データの利用目的

入力に関するデータは、日本語入力、単語登録、候補の学習を提供する目的に限って利用します。入力内容や登録語を広告、販売、信用力の判定に利用しません。作者が利用者のブラウザー内の入力内容や辞書を遠隔で閲覧する機能はありません。

HerissonSKK によるユーザーデータの取り扱いは、Limited Use 要件を含む [Chrome Web Store ユーザーデータポリシー](https://developer.chrome.com/docs/webstore/program-policies/limited-use)に準拠します。

## 問い合わせ

[GitHub Issues](https://github.com/yhayase/HerissonSKK-browser/issues) で受け付けます。投稿は公開されるため、個人情報や秘密の入力内容を記載しないでください。
