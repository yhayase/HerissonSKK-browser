# 0.1.2 リリースノート

ストアのバージョンノート欄に掲載する文案です。

- iframe 内の入力欄に対応しました。MDN の HTML サンプルなど、ページに埋め込まれた入力欄でも利用できます。
- 候補削除（大文字 X）の確認表示を改善しました。削除する語と Y／N の操作を明示し、警告表示が削除後に残る問題を修正しました。削除対象は個人辞書の候補です。
- 候補メニューと単語登録画面で日本語向けのフォントが選ばれるよう改善しました。
- カタカナモードで Ctrl+j を押したとき、ひらがなモードへ変わる問題を修正しました。確定後もカタカナ入力を続けられます。

候補メニューと単語登録画面は iframe の外側には表示できません。Android の Firefox は物理キーボードでの利用を対象とします。
