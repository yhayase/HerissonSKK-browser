# M1: 日常試用の確認記録

[ロードマップ](./roadmap.md#m1-日常試用の開始)の M1 を進めるための手順と記録です。実機で確認した結果を記入します。自動テストの成功だけでは実機確認済みにしません。

## 進め方

まず PC の Chrome で基本操作と再起動後の保持を確認し、日常的に使うサイトで試用を始めます。Firefox は非掲載版の署名済み XPI を準備し、PC、物理キーボードを使う Android で同じ項目を確認します。導入経路はロードマップに記載しています。

Chrome 用は `npm run build` で生成し、`chrome://extensions` の開発者モードで `.output/chrome-mv3` を読み込みます。更新時も同じ配置場所とプロファイルを使います。拡張機能を読み込む前から開いていた試用ページは再読み込みします。

Firefox 用の提出パッケージは `npm run zip:firefox` で生成します。生成した ZIP は署名済み XPI ではありません。署名と導入の準備状況を記録してから継続利用の確認へ進みます。既存の `npm run start:firefox` は WebDriver による一時インストールなので、日常試用の導入・再起動確認には使いません。

## 確認手順

1. 通常の Web ページの入力欄で `Ctrl+j` を押し、かな入力を開始します。`nihongo` などを入力し、文字の欠落や二重入力がないことを確認します。
2. `Nihongo`（先頭を `Shift+n`）、Space で変換し、候補を選択・確定します。別の変換で `Ctrl+g` によるキャンセルと、その後も入力を続けられることを確認します。
3. 辞書にない読みを変換し、登録画面で試用用の単語を登録します。読みと登録語を記録し、もう一度変換して呼び出せることを確認します。
4. 複数候補のある読みで先頭以外を確定し、再変換時に学習した候補が優先されることを確認します。読みと選択した候補を記録します。
5. [システム辞書設定](./system-dictionaries.md)で保存済みの構成を記録します。ブラウザを完全に終了して同じプロファイルで再起動し、拡張機能が利用でき、登録語・学習順・辞書構成が保持されることを確認します。
6. 日常サイトでも入力・変換・改行・Undo・通常のショートカットを試します。候補や登録画面の見切れ、入力欄を切り替えた際の問題を記録します。Android では特に `Shift` 同時押し、`Ctrl+j`、`Ctrl+g` と、狭い画面での操作を確認します。
7. 修正版が用意できたら、同じ拡張機能を更新します。更新前後のバージョンとコミットを記録し、ページの再読み込み後に登録語・学習順・設定と基本入力を再確認します。アンインストールによる入れ直しは更新確認に含めません。

ユーザーから、Firefox for Android で物理キーボードの `Ctrl+j` によりかなモードに移行した後、Gboard の Alphabet モードで問題なく入力できたとの報告がありました。ソフトウェアキーボードでの入力が常に不可能という扱いにはしません。

この報告に対応する拡張・Firefox・Gboard のバージョン、予測入力・自動修正の設定、試した入力欄は未記録です。ソフトウェアキーボード単独での起動、`Ctrl+g` 相当のキャンセル、登録からの復帰、候補操作全体を確認済みとは扱いません。

## Firefox / Android 0.1.1 の確認報告（2026-09-23）

Xiaomi Pad 8 で、案内した確認項目の範囲では問題がなかったとの報告がありました。対象は送り仮名の促音（`TasSi`、`TsukaTte`）、候補操作・キャンセル、単語登録・学習、再起動後の保持・オフライン利用、表示位置と普段の入力欄です。個別サイトや OS・Firefox のバージョンは未記録で、任意に挙げたサイトすべての確認を意味しません。

別途、MDN の `input type="text"` のサンプルでは拡張が有効にならず、ページ内の検索欄では使えるとの報告がありました。原因は content script が最上位フレームだけに読み込まれる設定だったことです。埋め込み文書への対応後、PC の Firefox で MDN の冒頭の対話サンプルと本文のサンプルの両方にかな入力できることを確認しました。ページの描画後は Shadow DOM 内の別オリジンの iframe が使われます。修正版の Android 実機確認は未実施です。対応範囲と制約は[埋め込み文書での入力](./embedded-documents.md)に記載しています。
