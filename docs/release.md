# 初回公開の準備

日常試用と並行して進める公開準備を管理します。公開の到達条件は[ロードマップ](./roadmap.md)、実機の結果は[日常試用の確認記録](./daily-trial.md)を参照してください。

## 配布物

```sh
npm ci
npm run compile
npm run zip
npm run zip:firefox
```

Chrome 用 ZIP と Firefox 用 ZIP は `.output/` に生成します。Firefox 用 ZIP は未署名です。公開・更新時は公開する変更とバージョンを確定し、提出したファイルのハッシュとコミットを記録します。初回公開バージョンは `0.1.0` です。旧 `0.0.0` は試用版です。

通常ビルドと ZIP の両方から `test.html` とテンプレート画像 `wxt.svg` を除外します。試験ページは `test/browser/test.html` をローカル HTTP サーバーから配信するため、開発・E2E では引き続き利用できます。manifest の公開リソースからも `test.html` を除外しています。

2026-09 の署名済み試用版は `de2e9c6fba9b4615b020-0.0.0.xpi` です。ユーザーの報告では、この署名時にはソースコードを提出していません。次回提出で追加資料を求められた場合は、その提出物を再現するソースとビルド手順を用意します。

## 基本辞書の初回ダウンロード（2026-09-23）

配布 ZIP に基本辞書を含めず、初回起動時に公式の S 辞書（JSON）を取得します。取得失敗は設定画面から再試行でき、成功後は再起動時にも保存済み辞書を使います。旧同梱辞書の設定・キャッシュを維持して、更新先を公式 URL に移行します。

GPL 辞書と本文は試験用として `test/fixtures/dict/` に保持します。ブラウザー拡張の ZIP には含めません。プライバシーポリシーと掲載文案を初回通信に合わせて更新しました。候補表示の性能測定は実際にダウンロードする辞書を使うため、レポート schemaVersion 3 では辞書が固定されていないことを明記します。固定辞書を使うパーサー／ストレージ検証は引き続き試験用データを使います。

## 2026-09-23 の更新: リポジトリからの公式辞書の削除
