# 候補削除（`X`）の表示と状態

インライン候補を表示しているときに大文字の `X` を押すと、候補削除の確認に移ります。対象は選択中の候補に対応する**個人辞書の登録・学習**です。システム辞書そのものは変更しないため、同じ候補がシステム辞書にもある場合は、後の変換で再表示されます。候補一覧上の `X` に新たな操作は割り当てません。

確認表示は候補注釈や送り仮名とは別の領域を使います。読み、削除対象の候補、送り仮名がある場合はその文字列、`Y：削除　N：戻る` を表示します。辞書登録中のミニバッファでも同じ情報を入力欄の下に表示し、入力欄のフォーカスと登録済み文字列は保ちます。内部の辞書キーは送り仮名のローマ字を含むことがありますが、画面には読みと送り仮名を分けて示します。

| 入力 | 動作 |
| --- | --- |
| 大文字の `Y` | 個人辞書へ削除を一度だけ依頼します。成功後、今の変換を終え、未確定の読み・候補・送り仮名・確認文を消します。本文には文字を追加しません。登録画面内では、確定済みの登録文字列は保ちます。 |
| 大文字の `N`、`Ctrl+G`、`Escape` | 削除せず、同じ候補と選択位置へ戻します。確認中の警告は残しません。 |
| 小文字の `y`・`n` | 確認を維持し、大文字で入力するよう表示します。 |
| その他の文字、Space、Enter、Backspace、Ctrl+J | 確認を維持し、`Y` または `N` を促します。本文は編集しません。 |

削除先が対象なしを返した場合は「個人辞書に削除対象がありません」と表示します。通信・保存の失敗は失敗として表示し、`Y` で再試行、`N` で取消ができます。削除依頼を受け付けた後は処理中を表示して重複操作を受け付けません。フォーカスが別の入力欄やウィンドウへ移った場合、古い確認画面を破棄します。すでに送った削除依頼は取り消せませんが、その完了結果で新しい入力欄の表示や状態を書き換えません。

確認表示に専用状態を設け、通常のステータスや候補注釈へ警告を保存しない設計です。これにより、取消後に `Y or N` の警告が候補表示へ残ることを防ぎます。
