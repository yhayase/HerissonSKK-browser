# SKK 辞書登録・再帰辞書登録 状態遷移仕様書

本ドキュメントは、SKK（特に標準実装である DDSKK `~/tmp/ddskk/skk.el` の `skk-henkan-in-minibuff`）の仕様に準拠した、辞書登録モードおよび再帰辞書登録モードの厳密な状態遷移とキー操作仕様を定義します。

実装（Implementation）とテスト（Tests）は、本仕様書に定義された要件番号に基づいて作成されなければなりません。**実装の現行コードに基づいてテストを作成してはならず、本仕様を満たすようにテストと実装を同期させます。**

---

## 1. 状態および用語の定義

| 状態名 / 用語 | 定義 |
| :--- | :--- |
| **`KakuteiMode`** | 確定入力状態。入力された仮名は即座にバッファへ確定挿入される。 |
| **`MidashigoMode`** | 見出し語入力状態（`▽`）。平仮名・片仮名・送り仮名の見出し語を編集中。 |
| **`InlineHenkanMode`** | インライン単独候補選択状態（`▼`）。第 1〜3 候補をインライン表示。 |
| **`MenuHenkanMode`** | 複数候補一覧選択状態。ラベル（`a`〜`g` など）によるページネーション表示。 |
| **`RegistrationMode`** | 辞書登録モード。ミニバッファ（仮想エディタ）内で登録語を編集する。 |
| **再帰深度 (`depth`)** | 辞書登録の入れ子レベル。最上位（親）は `depth = 1`。登録編集中にさらに未登録語の変換に入った場合は `depth >= 2`（再帰辞書登録）。 |
| **ミニバッファ (`miniBufferEditor`)** | 実 DOM を汚染せず、インメモリで文字列や未確定状態（`▽`/`▼`）を保持する仮想エディタ。 |

## 2. 送りあり見出し語の生成規則 (`SPEC-OKURI-01`)

DDSKK [`skk.el:L2363-L2373`](file:///home/hayase/tmp/ddskk/skk.el#L2363-L2373)（`skk-compute-henkan-key2`）に準拠します。

1. **内部辞書検索・保存キー (`dictionaryKey`)**:
   - 送りなし: `見出し語`（例: `にほん`）
   - 送りあり: `語幹 + 送りアルファベット`（例: `うs`、`かt`）
2. **UI 表示用見出し語 (`displayMidashigo`)**:
   - 送りなし: `見出し語`（例: `にほん`）
   - 送りあり: `dictionaryKey` の末尾アルファベット（`[a-z]+$`）を除去し、`語幹 + "*" + 送り仮名` とする。
     - 入力 `USi` → 語幹 `う`, 送りアルファベット `s`, 送り仮名 `し` → **`う*し`** （`うs*し` や `かt*つ` は不可）
     - 入力 `Kat` → 語幹 `か`, 送りアルファベット `t`, 送り仮名 `つ` → **`か*つ`**
3. **プロンプトヘッダ表示**:
   - `depth = 1`（最上位）: `[見出し] ` または `[辞書登録] 見出し: `（HUD 表示: `[う*し] `）
   - `depth >= 2`（再帰時）: `depth` に応じてブラケットが多重化されるか、再帰登録バッジとともに `[う*し] ` を表示。

## 3. キー入力と状態遷移仕様

### 3.1. Enter (`RET`) による確定と中断復帰 (`SPEC-KEY-ENTER`)

- **要件 3.1.1 (非空確定)**: ミニバッファに確定文字列が存在する場合:
  - 辞書プロバイダ（個人辞書）に `dictionaryKey` と登録語（送りありの場合は語幹）を保存する。
  - `depth >= 2`（再帰時）: 親のミニバッファへ登録文字列を挿入し、親の `RegistrationMode` に復帰する。
  - `depth = 1`（ルート時）: 実 DOM エディタへ確定文字列を挿入し、元の通常モード（`KakuteiMode`）に復帰する。
- **要件 3.1.2 (空文字中断復帰)**: ミニバッファが空文字列（未入力）の状態で `Enter` が押された場合:
  - **辞書登録を中断し、直前の変換状態へ復帰する。**
  - **復帰先 A (単独候補末尾からの突入時)**:
    - 辞書登録に入る直前に表示していた単独候補（末尾候補）を再表示した `InlineHenkanMode` に復帰する。
  - **復帰先 B (候補一覧メニューからの突入時)**:
    - 辞書登録に入る直前に表示していた最後の候補リストページを表示した `MenuHenkanMode` に復帰する。
  - **復帰先 C (候補 0 件で見出し語から直接突入時)**:
    - 直前の見出し語（`▽`）を保持した状態に復帰する。
  - 再帰登録（`depth >= 2`）で空文字 Enter が押された場合は、親のミニバッファの直前の変換状態へ復帰する。

### 3.2. Ctrl+j (`skk-kakutei`) によるバッファ内確定 (`SPEC-KEY-CTRLJ`)

- **要件 3.2.1 (バッファ内変換確定)**:
  - ミニバッファ内で `▼`（候補選択中）の場合: 現在の候補をミニバッファ内の平仮名／漢字として確定固定する。
  - ミニバッファ内で `▽`（見出し語入力中）の場合: 見出し語をそのまま仮名として確定固定する。
  - 未消化ローマ字（例: 末尾の `n`）がある場合: 仮名（`ん`）に変換して確定固定する。
- **要件 3.2.2 (空文字・確定済みの無操作)**:
  - ミニバッファ内に未確定（`▼`、`▽`、ローマ字）がない場合（既に平仮名に確定されている、または空文字列の場合）:
  - **何も起きない（No-op）**。
  - **ミニバッファ（辞書登録モード）を抜けてはならない。**

### 3.3. Backspace (`DEL`) によるバッファ内文字削除 (`SPEC-KEY-BS`)

- **要件 3.3.1 (バッファ内文字削除)**:
  - ミニバッファ内に文字が存在する場合、末尾の 1 文字を削除する。
- **要件 3.3.2 (空バッファ時の無操作)**:
  - ミニバッファが空文字列の状態で `Backspace` が押された場合:
  - **何も起きない（No-op / エラー音相当）**。
  - **再帰登録モードを一段抜けたり、登録モードをキャンセルしてはならない。**

### 3.4. Ctrl+g (`keyboard-quit`) による段階的キャンセルと 1 段脱出 (`SPEC-KEY-CTRLG`)

- **要件 3.4.1 (バッファ内未確定の段階的キャンセル)**:
  - ミニバッファ内が `▼`（候補選択中）の場合: 候補選択をやめて `▽`（見出し語編集）に戻す。
  - ミニバッファ内が `▽`（見出し語入力中）の場合: 見出し語を消去して通常の平仮名入力に戻す。
  - 未消化ローマ字バッファがある場合: ローマ字バッファを消去する。
- **要件 3.4.2 (再帰登録の 1 段脱出)**:
  - ミニバッファ内に未確定文字列・ローマ字がない状態で `Ctrl+g` が押された場合:
  - `depth >= 2`（再帰時）:
    - **再帰学習を 1 段抜けて、親の `RegistrationMode` に戻る。**
    - 全体がキャンセルされて `KakuteiMode` に戻ってはならない。
  - `depth = 1`（最上位時）:
    - 辞書登録を中止し、未確定状態を破棄して元の入力状態（`KakuteiMode`）へ復帰する。
