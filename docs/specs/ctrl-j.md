# Ctrl+j の動作

Ctrl+j はかな入力の開始・未確定入力の確定に使います。ひらがなとカタカナの切り替えには使いません。待機中のかな種別の切り替えは `q` で行います。

| 操作前の状態 | Ctrl+j の結果 |
| :--- | :--- |
| ひらがな・カタカナで待機中 | 入力内容とかな種別を維持します。 |
| かな入力中の未完のローマ字 | 未完のローマ字を解除し、かな種別を維持します。 |
| 見出し語の入力中 | 入力済みの読みを確定し、かな種別を維持します。 |
| 変換候補の選択中 | 選択中の候補を確定し、かな種別を維持します。 |
| ASCII・全英モード | 既存仕様どおり、ひらがな入力を開始します。 |
| 単語登録中 | 登録用入力欄の既存の確定処理に委譲します。登録自体は完了しません。 |
| 候補削除の確認中 | 削除やかな切り替えは行わず、Y または N の入力を求めます。 |

今回の修正は、ブラウザ側のキー処理でカタカナ待機中にひらがなへ切り替えていた分岐を修正するものです。ASCII・全英モードへ移る前のかな種別を記憶して復帰する機能や、登録中の未完ローマ字の扱いは変更しません。

DDSKK の `skk-kakutei` は、かなモードでの確定時に `skk-katakana` を切り替えません。この点を互換性の基準とします。参照: [DDSKK skk.el](https://github.com/skk-dev/ddskk/blob/master/skk.el)（2026-09-23 確認）。
