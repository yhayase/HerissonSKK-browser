## 名前

- Firefox: HerissonSKK for Firefox
- Chrome: HerissonSKK for Chrome

## 概要

ブラウザーの入力欄で SKK 方式の日本語入力を使えます。かな漢字変換、単語登録、候補の学習をローカルで処理します。

## 説明

ローマ字でかなを入力し、変換する読みの先頭を Shift と一緒に入力して、Space で漢字に変換します。辞書にない単語は入力中に登録でき、登録語と学習した候補順は同じブラウザープロファイルに保存します。

通常の入力欄に加え、VS Code for the Web（vscode.dev）のエディターでも SKK 方式で日本語を入力できます。

初回起動時に基本辞書 S を自動ダウンロードします。初回はインターネット接続が必要です。取得後はオフラインでも利用できます。取得に失敗した場合は、辞書設定画面で初期化を再試行できます。設定画面ではシステム辞書の追加、並べ替え、有効・無効の切り替えができます。外部 URL やローカルファイルからの辞書追加にも対応します。

入力内容や登録語を変換サーバーへ送信しません。外部辞書の取得・更新時には、その辞書の配信先へ通信します。取得済み辞書による変換はオフラインでも利用できます。

## 制作と AI の利用

HerissonSKK は Yasuhiro Hayase が制作・公開しています。開発には Google Gemini と OpenAI Codex を使用し、コード・テスト・文書の作成や修正、検証作業に AI を活用しています。アイコンは ChatGPT の画像生成で作成し、Codex を用いて調整・整形しました。作者が仕様や採用する変更・図案を判断し、動作を確認しており、公開内容に対する最終的な責任は作者が負います。

AI は開発・制作時に利用しています。拡張機能の日本語変換は取得済みの SKK 辞書を使ってブラウザー内で処理し、入力内容や登録語を AI サービスへ送信しません。

## 基本操作

1. 通常の Web ページの入力欄で `Ctrl+j` を押し、かな入力を始めます。
2. `Nihongo`（先頭は `Shift+n`）と入力し、Space で変換します。
3. 候補を選び、Enter で確定します。`Ctrl+g` で変換をキャンセルできます。
4. 辞書にない読みは登録画面で単語を登録します。

詳しい辞書設定は[システム辞書の設定](./system-dictionaries.md)を参照してください。

## 対応範囲と制約

- PC の Chrome・Firefox、物理キーボードを使用する Android の Firefox を対象に検証しています。
- Android のソフトウェアキーボードは対応対象に含めません。
- ブラウザーの内部ページや拡張機能の動作を制限するページでは利用できません。サイト独自の入力欄では動作が異なる場合があります。
- 辞書・学習・設定はブラウザーやプロファイルをまたいで同期しません。
- 個人辞書のインポート・エクスポート用画面は未実装です。
