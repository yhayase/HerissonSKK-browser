# HerissonSKK アイコン

採用したハリネズミとキーボードの図案です。文字は含めません。

- `HerissonSKK-master.png`: 承認済みの透過 PNG 原本（1254 × 1254）。
- `HerissonSKK-512.png`: ストア素材用の 512 × 512 PNG。
- `../../public/icon/`: 拡張機能用の 16・32・48・96・128 px PNG。WXT が manifest に設定します。

配色・構図を維持し、原本から Lanczos 法で縮小しています。原本は画像生成による図案の修正版です。小さい表示ではキートップなどの細部が省略されます。

## 制作と AI の利用

このアイコンは Yasuhiro Hayase が制作・公開する HerissonSKK のブランド素材です。ChatGPT の画像生成で図案を作成し、Codex を用いて品質調整とアイコン用の整形を行いました。作者が図案と調整結果を選定・確認し、公開内容に対する最終的な責任を負います。
